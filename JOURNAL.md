## 17.11.2026 — ручное обогащение реальными данными, двойная разметка, codebook

**Задание к 18.11:** (1) обогащение датасета руками реальными данными; (2) разметка не менее 50 объектов двумя аннотаторами; (3) codebook разметки.

**Сбор реальных данных** (`src/collect_real.py`, воспроизводимо, `random_state=42`). По лекции 15 (слайд «Ручной сбор данных») открытые датасеты — один из способов ручного сбора.

| | Тексты → RuSentiTweet | Фото → TrashNet |
|---|---|---|
| Источник | корпус Skoltech «Inappropriate messages» (Babakov et al., 2021), реальные сообщения пользователей русскоязычных платформ, CC BY-NC-SA 4.0 | TrashBox (Kumsetty et al., 2022), реальные фото отходов из интернета |
| Отбор | только сообщения без чувствительной темы; 4–30 слов; нет в RuSentiTweet; 40 случайно + 30 целевым отбором по маркерам редких классов (спасибо, поздравляю, люблю, круто…) | 63 фото по плану на все 6 классов TrashNet, включая trash (тетрапак, бумажные стаканы, окурки, маски, перчатки); ≤ 512 px, без EXIF |
| Объём | 70 | 63 |
| Очистка | маскирование ссылок, @упоминаний, почты, телефонов | отброшено 6 фото — копии TrashNet (pHash ≤ 4) |

**Что показал анализ** (`notebooks/02_eda_real_enrichment.ipynb`):
- новые тексты вдвое длиннее твитов (медиана 11 слов против 6), без упоминаний, ссылок и эмодзи; около 20 % словоупотреблений нет в словаре RuSentiTweet — это соседний домен;
- случайная выборка из форумного источника почти целиком нейтральна, поэтому для редких классов понадобился целевой отбор;
- новые фото разнообразнее TrashNet: разные размеры и пропорции, разброс яркости почти в 3 раза больше;
- **утечка данных:** TrashBox содержит фото из самого TrashNet (например, `paper104.jpg`); без проверки по pHash они попали бы и в исходные, и в «новые» данные.

**Codebook** v1.1: `docs/codebook_text.md`, `docs/codebook_images.md`.
- Тексты: правила сверены с официальной инструкцией RuSentiment, по которой размечен RuSentiTweet (смайлики как единственный признак эмоции → `neutral`; шутки и неясная тональность → `skip`; «скучаю» → `negative`). Уточнения — по расхождениям исходной разметки: «да/нет/ок» → `neutral`; «спасибо» → `speech`.
- Фото: материал, а не форма; тетрапак, бумажные стаканы, окурки, маски → `trash`; метка `exclude` для непригодных веб-фото (рисунки, постеры, не отходы).

**Разметка (18.11):** размечали по codebook v1.1, каждый отдельно, не видя меток друг друга и классов источника:

Основные расхождения в текстах: `neutral` и `skip` на коротких или обрывочных сообщениях (4 случая), благодарность в начале содержательного сообщения (`speech` или `neutral`), рекламная формулировка (`positive` или `skip`). В фото — стоковые коллажи и мелкие предметы (`exclude` или класс). Расхождения разобрали вместе по codebook и для каждого записали обоснование (`data/annotation/arbitration.csv`).

**Эффект на баланс классов** (`reports/eda_after/class_balance_before_after.csv`): дисбаланс фото $4{,}34 \to 3{,}99$ (класс `trash`: $137 \to 150$); тексты $10{,}77 \to 10{,}73$. При таком объёме ручное обогащение почти не меняет баланс; его главная ценность — тест из другого домена.

**Проблемы и решения:**
- Нет доступа к API соцсетей без ключей → использован открытый корпус реальных сообщений.
- Случайная выборка почти без `speech` и `positive` → добавлен целевой отбор по маркерам, способ отбора сохранён в колонке `sampling`.
- Копии TrashNet в TrashBox → фильтр по pHash при отборе.
- Метки источника TrashBox не совпадают с нашими классами (тетрапак и бумажные стаканы у них — «paper») → в листы разметки не передаются, класс определяют разметчики по codebook.
